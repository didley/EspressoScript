The toolchain

What ShotScript adds.

ShotLint is the portable rule engine — drop it into any TypeScript project. ShotScript goes further: a full, locked-down environment where the rules are the runtime.

ShotLint vs ShotScript: ShotLint enforces Shot's rules on any .ts file. ShotScript enforces those rules plus strict import isolation, a baked-in tsconfig, the shot:std standard library, and the shot CLI pipeline — with no configuration surface at all.
Strict import isolation

.shot files may only import from shot:* (the standard library), bun:* (Bun built-ins), or relative paths ending in .shot. No arbitrary npm imports. Third-party dependencies are adapted via shot_modules/ adapters that wrap external code in a Shot-compliant interface.

Zero configuration

No tsconfig.json. No .eslintrc. No config files to manage or drift. The shot CLI bakes in its own compiler options and rule set on every invocation. Rules are part of the language, not a preference — you can't turn them off.

The .shot extension

Every .shot file is valid TypeScript — the full type system, ecosystem, and tooling work unchanged. The extension signals Shot compliance the same way .go signals Go: this file plays by the rules of the environment.

shot:std

A standard library for I/O, HTTP, and JSON — all returning result tuples, none of which throw. safeFetch, jsonParse, readFile, writeFile, wrapError. The same pattern as your own code.

Gated pipeline

shot run and shot test gate on correctness before execution: lint fails → type errors → never runs. Build output is guaranteed clean. No separate pre-commit hooks needed.

shot_modules/ adapters

When you need a third-party library, place a .shot adapter in shot_modules/. The adapter wraps the external API in Shot's tuple-return contract. Your project code stays pure; the adapter is the only boundary.

Tooling

One command, five verbs.

shot's pipeline gates on correctness before it executes. Lint fails → type errors → never runs.

terminal
# scaffold a project
$ shot init my-app

# lint only
$ shot check src/

# format — zero config, one canonical output
$ shot fmt

# run (lint → type-check → execute)
$ shot run src/main.shot

# test (lint → type-check → run *.test.shot)
$ shot test
