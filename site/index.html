Ecosystem

Two tools, one philosophy.

ShotLint is the portable rule engine. ShotScript is the full toolchain built on top of it.

Toolchain
ShotScript

The full opinionated TypeScript environment. .shot files, the shot CLI, and a standard library — all with rules enforced by default, no config.

  • .shot files — valid TypeScript, Shot-compliant
  • shot CLI — init · check · fmt · build · run · test
  • shot:std — safe wrappers that never throw
  • Import allowlist — shot: and relative .shot paths only
  • No config — rules are the language, not a preference

Linter
ShotLint

90+ AST rules enforcing one canonical form per TypeScript construct. Drop it into any existing project — no special runtime or file extension required.

  • 90+ rules — functions, types, errors, control flow
  • Standalone CLI — npx shot-lint 'src/**/*.ts'
  • Plugin API for ESLint and other toolchains
  • Available on npm
  • Works with any TypeScript project or framework
