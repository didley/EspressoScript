Standard Library

shot:std

The standard library. Ships as @shotscript/std on NPM; imported via the shot:std specifier in .shot source. Every function returns a tuple — never throws. Internal try/catch is hidden inside the wrappers; user code never sees it.

Import: import { safeFetch, jsonParse, wrapError } from "shot:std"
import type { Result, PromiseResult } from "shot:std"
Result<T, E> type

The canonical return type for synchronous fallible functions. A discriminated union — either [T, null] on success or [null, E] on failure. E defaults to Error but can be any plain type. 

type Result<T, E = Error> = [T, null] | [null, E]

// usage
function parseConfig(src: string): Result<Config> {
  return jsonParse<Config>(src)
}
PromiseResult<T, E> type

The canonical return type for async fallible functions. Shorthand for Promise<Result<T, E>>. 

type PromiseResult<T, E = Error> = Promise<Result<T, E>>

// usage
async function queryUser(id: number): PromiseResult<User> {
  const [res, err] = await safeFetch(`/users/${id}`)
  if (err !== null) { return [null, err] }
  return jsonParse<User>(await res.text())
}
safeFetch(url, opts?) async

Wraps globalThis.fetch. Returns [Response, null] on success, [null, Error] on network failure. HTTP error status codes are not treated as errors — check res.ok yourself. 

function safeFetch(
  input: string | URL,
  init?: RequestInit,
): PromiseResult<Response>

const [res, err] = await safeFetch(`https://api.example.com/users/${id}`)
if (err !== null) { return [null, err] }
if (!res.ok) { return [null, new Error(`HTTP ${res.status}`)] }

readFile(path) async

Wraps node:fs/promises readFile. Returns file contents as a UTF-8 string, or an error. 

function readFile(path: string): PromiseResult<string>

const [text, err] = await readFile("./config.json")

Wraps node:fs/promises writeFile. The first tuple element is always null for void-returning operations — the destructure pattern stays uniform.

wrapError(message, cause) sync

Adds context to a propagated error — the shot equivalent of Go's fmt.Errorf("context: %w", err). Sets err.cause so the original error is inspectable. 

function wrapError(message: string, cause: Error): Error

const [text, err] = await readFile(path)
if (err !== null) {
  return [null, wrapError(`loadConfig: ${path}`, err)]
}
toResult<T>(fn) sync

Wraps any synchronous third-party call that might throw. Use when importing bun:* or node:* APIs that don't return tuples. 

function toResult<T>(fn: () => T): Result<T>

const [parsed, err] = toResult(() => someLib.parseSync(input))
toPromiseResult<T>(fn) async

Wraps any async third-party call that might reject. Use when importing bun:* or node:* APIs that return plain Promises. 

function toPromiseResult<T>(
  fn: () => Promise<T>,
): PromiseResult<T>

const [rows, err] = await toPromiseResult(() => db.query(sql))

All wrappers internally use try/catch to convert thrown errors into the second tuple slot. The ban on try/catch applies to .shot user code; stdlib is .ts and exempt. Errors from stdlib wrappers are returned as Error instances.
